# Marca do canal Rasura

> Data: 2026-11-14 · Tipo: assets · Status: em avaliação

**Resumo:** avatar, banner e tela final do canal Rasura, feitos a partir da pintura de um fantasma enviada pelo dono. A marca é a palavra RASURA com um risco vermelho de caneta por cima, como num trecho riscado de documento. Paleta do estúdio: creme, vermelho e amarelo marca-texto, com as fontes dos vídeos (Anton e a de máquina de escrever).
